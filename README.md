# 3D-демо ЖК для встреч с застройщиками: C1 и NRG Mirzo Ulugbek

Интерактивный 3D-макет реального строящегося дома, собранный **только из открытых данных** и без ручного 3D-моделирования:
дом на своём месте → этаж в разрезе → квартира со статусом → прогулка внутри → VR.

> ⚠️ **Не публиковать.** Поэтажные планы и статусы квартир — данные застройщика (mbc.uz).
> Демо показывается локально с ноутбука. Выкладка по ссылке — только с согласия застройщика или за паролем.

## Запуск

```bash
cd web && npm install && npm run dev
```

Откроется на http://localhost:5180 — ЖК C1. Второй ЖК: http://localhost:5180/?p=nrg-mirzo-ulugbek
(или переключатель справа вверху). Чтобы показать на телефоне в той же Wi-Fi-сети, откройте на нём адрес,
который Vite печатает в строке `Network:`.

Пересобрать данные (после изменения скриптов или новых снимков):

```bash
python3 -I tools/register.py     # совмещение планов этажей по лифтовому ядру → data-src/registration.json
python3 -I tools/build_api.py    # снимки → api-stub/ (≈30 с)
python3 -I tools/build_massing.py   # NRG Mirzo Ulugbek: корпуса, места рядом, тестовые планировки и шахматка
```

## Сценарий показа на встрече (3 минуты)

1. **Дом на своём месте.** Башня на реальном участке у перекрёстка, рядом семиэтажки с Махтумкули, канал Салар, эко-парк Бобура.
   Ползунок времени внизу двигает солнце и тени: «вот так дом освещён в 9 утра в декабре».
2. **Этаж.** Клик по этажу (или по рейке слева) — этаж срезается, квартиры подсвечены по статусу из вашего каталога.
3. **Квартира.** Карточка: площадь, этаж, высота окон, стороны света, **что видно из окон** (по карте), **часы солнца** на выбранную дату с учётом соседних домов.
4. **Прогулка.** «Пройти по квартире» — WASD и мышь, на телефоне джойстик. За окном — реальное окружение на высоте этажа.
5. **Главная фраза:** «Это собрано без ваших файлов — по картинкам с вашего сайта. С DWG-чертежами будет точнее, плюс отделка, мебель, вид с дрона и живые статусы из CRM».

## Что условно для NRG Mirzo Ulugbek

- Высоты этажей: 1-й — 3,6 м, остальные — 3,0 м; фасад стилизован (сетка окон), не «неоклассика» как в жизни.
- Этажность по OSM; у блока 26/13 в 2ГИС указано 4 этажа, в OSM — 5.
- Данные 2ГИС не выгружались (условия сервиса запрещают копирование) — ЖК опознан по странице, геометрия и места — из OSM.
- Время пешком = расстояние × 1,25 / 80 м в минуту, без маршрутизации.

## Что условно для C1 (честно говорить, если спросят)

- Высоты этажей: 1-й — 4,8 м, подиум — 4,2 м, жилые — 3,3 м (разрезов нет).
- Фасад стилизован по рендеру застройщика; чертежей фасада нет.
- Стены извлечены автоматически из картинок планов, возможны мелкие неточности. Подписи площадей — для комнат до 38 м²; объединённые кухни-гостиные показываются одной цифрой.
- Соседние дома — упрощённые объёмы OSM; у части высота оценена по типу здания.
- Цена — «по запросу», как у застройщика: выдумывать нельзя.
- 3 этаж показан по плану 4-го (план 3-го не снят), 1 этаж — по плану 2-го.
- VR (WebXR) не проверен на реальном шлеме — шлема нет.

## Как устроено

```
data-src/   снимки источников на 04.11.2026 (см. SOURCES.md) — НЕ публиковать
tools/      planlib.py (растровая морфология без OpenCV), register.py (совмещение этажей), extract_floorplan.py (план → геометрия), build_api.py
api-stub/   API-контракт (CONTRACT.md) в виде JSON — временная замена бэкенда
web/        Vite + Vue 3 + TypeScript + three.js
  src/domain  типы, статусы, суммы, солнце, стороны света, вид из окон
  src/api     клиент /api
  src/scene   движок: окружение, здание, разрез, прогулка, VR
  src/ui      интерфейс
```

**Конвейер «картинка плана → 3D»:** маска стен по цвету → сетка 5 см → снятие дуг дверей и теней значков
(открытие 2×2, только прямые участки, сплошные блоки шахт) → контур перекрытия (закрытие разрывов + заливка) →
стекло по линиям окон → дверные перемычки по форме → комнаты как связные области → прямоугольники в метрах.
Масштаб — по площадям квартир каталога, совмещение этажей разных типов — корреляцией по лифтовому ядру.

**Вес:** весь первый экран (JS, CSS и все данные дома с окружением) — около 1 МБ, 277 КБ в gzip.
Рендер — на устройстве, без серверных видеокарт.

## Выкладка на сервер: https://lab.edu-start.org/nrg-bi/

Выложен **только ЖК NRG Mirzo Ulugbek** (C1 — планы Murad Buildings, без согласия застройщика не публикуется).
Статика отдаётся общим Nginx Proxy Manager, отдельного контейнера нет.

```bash
(cd web && npx vite build --base /nrg-bi/ --outDir ../deploy/nrg-bi --emptyOutDir)
python3 -I tools/pack_deploy.py deploy/nrg-bi nrg-mirzo-ulugbek
rsync -az --delete --chmod=Du=rwx,Dgo=rx,Fu=rw,Fgo=r deploy/nrg-bi/ edu_start:/opt/proxy/data/static/nrg-bi/
```

- Файлы на сервере: `/opt/proxy/data/static/nrg-bi` (в контейнере NPM — `/data/static/nrg-bi`).
- Маршрут: NPM, прокси-хост №5 (lab.edu-start.org) → поле **advanced_config** в базе NPM и тот же блок в
  `/opt/proxy/data/nginx/proxy_host/5.conf`: `location ^~ /nrg-bi/` с `alias`, `try_files $uri $uri.json …` (ответы API — файлы `.json`),
  gzip, `X-Robots-Tag: noindex`. Правка в базе нужна, чтобы блок пережил перегенерацию конфига (сохранение хоста, продление сертификата).
- Откат: резервные копии в `/opt/proxy/backups/` (`database.sqlite.*.before-nrg-bi`, `5.conf.*.before-nrg-bi`) → вернуть оба файла,
  `docker exec shared-nginx-proxy-manager nginx -t && … nginx -s reload`.
- Повторная выкладка файлов NPM не трогает — только `rsync`.
